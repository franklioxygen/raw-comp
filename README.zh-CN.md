## 功能特性

- 支持在一个窗口中同时对比 `2`、`3`、`4` 或 `6` 张图片。
- 支持打开常见图片格式以及多种常见相机 RAW 格式。
- 支持缩放、平移、旋转、适应窗口以及一键跳转到 `100%`。
- 支持联动或取消联动各个视图窗格，让所有图片同步移动或独立操作。
- 支持标记同步高亮区域，用于强调各图中对应的细节位置。
- 支持对所有已加载窗格统一应用非破坏性对比调整（光线、色调曲线、颜色、黑白、细节、噪点、光学、几何等）。
- 支持专业比较模式：裁剪叠加、边缘图、伪彩色、噪点强调、绝对差值、Delta E、闪烁与擦除（双窗格）。
- 支持保存/打开 `.rawcomp` 比较会话并恢复对应布局，并将当前视口下的比较网格导出为 PNG 或 TIFF。
- 支持直方图、像素读数与活动窗格的元数据查看。

## 当前状态

RawComp 是一款持续迭代中的专注对比工具。

当前已经比较稳定的能力：

- 多窗格并排查看（2 / 3 / 4 / 6）
- 视口联动或自由移动
- 同步高亮区域
- 分区式检查器（旁路、预设、自动保存）
- 直方图、裁剪指示与光标读数
- 比较模式（含差异、擦除、闪烁，双窗格布局）
- 会话保存/打开（含多窗格布局恢复）与比较导出
- 元数据查看与 8 种界面语言

仍在推进中的方向：

- 基于 LibRaw 的更完整 RAW 解码
- 文件夹浏览 / 胶片条工作流
- 会话中的评分与标记
- 厂商镜头配置文件与校准平场流程

调整系统说明：[comparison-adjustments-dev-spec.md](documents/comparison-adjustments-dev-spec.md)

## 支持格式

RawComp 旨在同时支持压缩图像和广泛的相机 RAW 格式。

当前识别的目标扩展名包括：

- RAW 与相机格式：
  `dng`, `arw`, `srf`, `sr2`, `cr2`, `cr3`, `crw`, `nef`, `nrw`, `raf`, `rw2`, `rw1`, `orf`, `ori`, `pef`, `ptx`, `kdc`, `dcr`, `k25`, `erf`, `mef`, `mos`, `iiq`, `3fr`, `fff`, `x3f`, `srw`, `bay`, `cap`, `tif`, `tiff`
- 标准格式：
  `jpg`, `jpeg`, `png`, `webp`, `heic`, `heif`, `gif`, `tif`, `tiff`

重要说明：

当前版本依赖 macOS 自带图像解码器以及 Quick Look 预览作为回退路径。这意味着某些 RAW 文件是否可用，取决于本机系统是否能直接解码或生成预览。在当前版本中，部分 RAW 文件打开后可能显示的是预览图，而不是完整解码后的传感器数据。

## 运行 RawComp

在仓库目录下执行：

```bash
swift run RawComp
```

也可以直接用 Xcode 打开 `Package.swift` 并运行应用。

## 基本工作流

1. 启动 RawComp。
2. 点击 `Open` 加载图片，或将文件拖放到某个窗格。
3. 选择布局：`2 Up`、`3 Up`、`4 Up` 或 `6 Up`。
4. 在 `Free` 和 `Synced` 联动模式之间切换，决定各窗格是否同步移动。
5. 使用工具栏中的缩放、适应窗口、`100%` 和旋转控制。
6. 使用 `Mark Region` 将当前可见区域记录为同步高亮区域。
7. 使用检查器中的滑杆统一调整所有已加载图片，让不易察觉的差异更明显。
8. 当你需要稍后恢复同一组布局时，保存 `.rawcomp` 会话；当你需要分享当前缩放视图时，从工具栏导出比较网格。

## 为什么统一调整很重要

有些图像差异在中性视图下并不明显，尤其是在阴影、低对比纹理、边缘、压缩伪影或细微噪点这些区域。

统一调整控件可以让你用相同方式同时推动每一张图，因此既保持比较公平，又更容易把这些差异看出来。

## 可调参数清单

- 光线：曝光、亮度、对比度、高光、阴影、白色色阶、黑色色阶、伽马
- 色调曲线：主曲线预设/自定义曲线、红通道预设/自定义曲线、绿通道预设/自定义曲线、蓝通道预设/自定义曲线
- 颜色：色温、色调、自然饱和度、饱和度、全局色相偏移
- 色彩混合器：红、橙、黄、绿、青、蓝、紫、洋红八个色带的色相、饱和度、明度
- 黑白：单色比较，以及红、橙、黄、绿、青、蓝、紫、洋红八个色带的明度
- 细节：清晰度、纹理、锐化强度、锐化半径、锐化细节、锐化蒙版、边缘图预览
- 降噪：明度降噪、明度细节、明度对比、色彩降噪、色彩细节、色彩平滑度、紫边去除、绿边去除、噪点强调预览
- 光学：镜头配置文件校正、畸变量、暗角量、色差去除、平场校正
- 几何：微调旋转、水平翻转、垂直翻转、裁切比例锁定、裁切叠加层、裁切框
- 比较模式：标准、仅明度、裁剪叠加、伪彩色、边缘图、噪点强调、绝对差值、Delta E、闪烁、擦除
- 比较模式设置：参考窗格、分析增益、擦除位置、闪烁间隔

## 规划方向

RawComp 的目标是成为一个专注的比较工具，而不是完整的照片库或 RAW 编辑器。

计划中的改进包括：

- 更强的 RAW 解码覆盖
- 更完善的高亮工具
- 文件夹与胶片条浏览
- 会话保存
- 比较结果导出
- 更多偏技术向的检查工具
